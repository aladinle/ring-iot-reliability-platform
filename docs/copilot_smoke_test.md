# Copilot Smoke Test

This file is intentionally harmless. It exists only to verify that GitHub Copilot or another coding assistant can make a small documentation change without affecting the working system.

## Suggested Test

Ask Copilot to update this file by adding one short checklist item under the section below.

## Checklist

- Repository opens successfully.
- CI workflow is present.
- Local tests can be run with `.\scripts\test_all.ps1`.

## Expected Result

Copilot should create a small documentation-only change. No source code, build configuration, deployment configuration, or runtime behavior should be modified.
